🧠 Interactive Quiz App

Welcome to the Interactive Quiz App — a simple yet engaging web-based quiz built with HTML, CSS, and JavaScript.
It’s perfect for anyone who wants to test their general programming knowledge while experiencing dynamic DOM manipulation in action!

🚀 Features

✅ Dynamic Questions: Each question is loaded dynamically from a JavaScript array.
✅ Score Tracking: Get instant feedback at the end of the quiz with your total score.
✅ Clean UI: Simple and minimal layout for distraction-free participation.
✅ Reload Feature: Restart the quiz anytime with a single click.

💻 Technologies Used
Technology	Purpose
HTML5	Structure of the quiz layout
CSS3	Styling and responsive design
JavaScript (ES6)	Dynamic logic, question handling, and score management
⚙️ How It Works

Each question (with four options) is stored in a JavaScript object inside an array.

When the quiz starts, the first question loads automatically.

Users select one answer and click Submit.

The script checks if the selected answer is correct and updates the score.

Once all questions are answered, the app displays the total score and a Reload button to restart.
